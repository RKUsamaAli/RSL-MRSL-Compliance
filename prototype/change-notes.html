For your confirmation
WhereWhat changedWhy
ProductsNew product and raw material registers. A product is tagged with raw materials; one raw material can be on many products.You asked to tag raw materials to a product and see them when searching. Keeping raw materials in their own register means a supplier or CAS correction reaches every product.
ProductsCAS numbers sit on the raw material, not on the product.Your workbook links CAS numbers to a product directly (Product_Input). We added the raw-material level you asked for, so its “Component / material” column becomes the raw material. Please confirm.
SearchThe substance search also lists matching products with everything attached. A chemical name also finds raw materials through their CAS number.A supplier sheet may state only “50-00-0”. A search for “formaldehyde” should still find it.
ProductsThe number beside a CAS chip counts list rows naming it. There is no pass or fail.Being listed is not a verdict. Verdicts need measured values and the numeric-limit decision (step 6).
CAS Screening HubThe workbook’s Master_Database sheet is a fourth category, with its own headings. 29 sample rows are loaded out of 22,822.A browser cannot hold the whole workbook with its version copies. The real system has no such limit. Uploads here take the first 1,000 rows and say so.
CAS Screening HubThe workbook’s calculated sheets (Dashboard, Screening_Results, Product_Summary, CAS_Index) are not reproduced.They are outputs of the product check, which is the next step.
TemplateEach list has its own template, built from its columns. Change a list’s columns and its template follows. The CAS column is formatted as text.Your lists have different layouts. Excel otherwise turns some CAS numbers into dates.
TemplateA grey Row ID column links a row to its record. Without it, rows are matched on CAS number + name + section (or on Record ID for the workbook).This is how a re-import knows a row was changed, not deleted and added again.
ImportNothing is saved until you confirm. The preview shows new, changed, removed and unchanged records, plus every error by Excel row number.A wrong file could otherwise remove a whole list.
ImportTwo ways to import: Replace the list (a new edition) or Add & update only (part of a list). Products start on Add & update.The same file means different things in the two situations, so the choice is made each time, with the effect shown first.
ImportOne error stops the import. Warnings, such as a failed check digit, do not.A half-loaded list is hard to notice later. Open question: this can change so that good rows go in and bad rows are left out.
VersionsEach import saves a complete version of the list. Any version can be viewed, compared, downloaded to Excel or reverted to.You asked for versions and revert. Whole copies keep restoring simple and exact.
VersionsRevert adds a new version; it deletes nothing. A revert can itself be undone.Compliance history should not lose records, and a wrong revert must be recoverable.
VersionsVersions cover each list separately, and products as one set. Row-by-row edits are saved as a “Manual edits” version before an import or revert.Reverting one list must not touch another, and manual work must never be lost silently.
VersionsWho imported is shown as a fixed name (“Compliance Officer”).The prototype has no users or logins yet.

Round 1 — data model decisions

For your confirmation
WhereWhat changedWhy
EverywhereEach document is a category with its own column list. Rows belong to one category.Your three documents have three different tables (8, 7 and 4 columns). One fixed table would force empty columns or lose data.
Category builderTwo columns carry a role: “CAS number” and “Chemical / substance name”. Headings can be worded however the document words them.You asked for CAS number and chemical name as the primary search across all lists. The search reads the role, so “CAS Number”, “CAS No.” and “CAS No” all behave the same.
Category builderColumns can sit under a header band (OEKO-TEX: Wastewater / Sludge over Limit Values and Reporting Limit).Reproduces the two-row header of the source so the team recognises the table; also disambiguates the two identical “Limit Values” headings.
Add rowEvery row carries a section title (“AP and APEO”, “1. Alkylphenols…”, “Part A”). Existing titles are offered as chips; the last one is remembered for the next row.The section title is how the documents group rows and how your team navigates them. In the table it renders as a band row, as in the source.
Add row — AAFAMerged cells in the PDF (the Restriction text spanning two rows) are entered on each row they cover.A search hit must return a complete row. Copy is cheap; a merged-cell model breaks search, export and later product checks.
Add row — CASSeveral CAS numbers in one cell are entered one per line. Free text (“Various”, “All CAS of isomers of NP”) is allowed in the CAS column.Both appear in your documents. Search matches each number separately, with or without dashes.
Add row — CASEach CAS number is checked against its check digit as you type: green = OK, amber = wrong digit. Saving is never blocked.Typos in CAS numbers are the most common data-entry error and are invisible later. A warning at entry time costs nothing.
Add row — CASDuplicate warning when the same CAS number already exists in the category (names the existing row).Documents sometimes list one substance under two groups; the operator should know, but must still be able to save.
OEKO-TEX — MRSL columnThe printed “X” becomes a Yes / No flag, shown as X in the table.A flag can be filtered (“is not empty”) and exported cleanly; a free-text “X” cannot.
OEKO-TEX — limit columnsLimit and reporting-limit columns are text, not number.The Sludge limit for Nonylphenol reads “testing required”. A numeric column would reject it. Open question: numeric comparison for the future product check.
SearchDefault search matches CAS + name only; a switch extends it to every column and the section title. Column filters (contains / equals / empty…) can be added on top.Your primary request; the any-column mode covers “search based on any parameter” without cluttering the default.
Search resultsResults are shown per category, each with its own headings; categories without a match collapse to one line.Different column layouts cannot share one grid. Collapsing keeps the page short while still showing where nothing was found.
Demo dataPOPs rows are illustrative samples (striped), paraphrased, not transcribed.You supplied column headings but no page image for POPs. Real rows should replace them.
