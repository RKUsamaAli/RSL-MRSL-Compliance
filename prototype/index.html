What is in this prototype

Five areas are working end to end, with data that persists in this browser between pages:

  • Categories — the three lists from your brief are pre-built. The category builder lets you add a new document: name it, list its column headings, mark which column is the CAS number and which is the chemical name, and optionally group columns under a band (OEKO-TEX “Wastewater” / “Sludge”).
  • Add row — pick the category, the form shows exactly its columns. Section title (“AP and APEO”) is remembered for the next row. Save & add another keeps you typing.
  • Search & data table — one search box for CAS number or chemical name across all categories; each category renders as its own table with its own headings and section bands. Optional filters on any column; click a row for the full record; export CSV. Products and their attached raw materials appear above the lists when they match.
  • Products & raw materials Round 2 — create a product, tag its raw materials, search it and see everything attached. Search a raw material or a CAS number and see which products use it.
  • Product report Round 3 — each product with its raw materials and CAS numbers, in your layout. Print it or download it to Excel.
  • Excel import & versions Round 2 — download a template for any list, fill it in, upload it, check the changes, then import. Every import is a version you can view, download or revert to.
Decisions still needed from you (each drops into config.js once answered):
  1. Should a row without a section title be allowed? Currently allowed — settings.requireSectionTitle.
  2. Search default: CAS + name only, or any column? Currently CAS + name — settings.searchMode.
  3. Numeric limit columns (OEKO-TEX 5 µg/l) also contain text (“testing required”). We kept them as text so both fit. Do you need numeric comparison later (for step 6)?
  4. Who may edit or delete a category once rows exist? Prototype allows it with a warning.
  5. Should one bad row stop a whole import, or should the good rows go in? Currently it stops — settings.importBadRows.
  6. Should a list import replace the list or only add and update by default? Currently replace, with the choice on screen — settings.importDefaultMode.
  7. Do CAS numbers belong to the raw material, or do you also need them per product and component, as in the workbook’s Product_Input sheet? Currently on the raw material.
