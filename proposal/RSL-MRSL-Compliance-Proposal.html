What you are getting

Your CAS Screening Hub workbook holds 22,822 records from 65 source standards. It works well as a spreadsheet, but every new edition means reworking the file, and nothing shows what a list looked like before it changed.

We will turn it into a web system. Your team will be able to search any CAS number or chemical name across every list, see which products and raw materials are involved, and load new editions from Excel with a full version history to go back to.

You can try it today. The prototype shows the screens this proposal covers, using demonstration data:

What is included

Lists and columns

One category per source document, each with its own columns and headings, because every standard lays out its table differently.

Search

Search by CAS number, with or without dashes, or by chemical name across every list at once. Add filters on any column and export the results.

Row entry and checks

Add or edit a single row. CAS numbers are checked against their check digit, and duplicates are flagged.

Products and raw materials

Create products and tag raw materials to them. Search a product to see everything attached, or a raw material or CAS number to see which products use it.

Excel template and import

Download a template for any list, fill it in and upload it. You see every new, changed and removed record, and every error by row number, before anything is saved.

Versions and revert

Every import is kept as a version you can view, compare, download or restore. Reverting never deletes history.

Sign-in

Your team signs in with individual accounts, so each version shows who made it.

First data import

You provide your data in Excel, in the template layout, and we import it once. No row limit applies, unlike the prototype.
